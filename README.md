# 🏆 PRODE Copa Mundial 2026

Aplicación web para participar en el PRODE (Pronóstico Deportivo) de la Copa Mundial 2026.

## ✨ Características

- 🔐 Autenticación segura
- 📊 Panel de administración
- 🎯 Pronósticos en tiempo real
- 📈 Ranking automático
- 💾 Base de datos MongoDB
- 📱 Diseño responsive

## 🎮 Uso

1. Abre https://prode-2026.vercel.app
2. Login con DNI y contraseña
3. Haz tus pronósticos
